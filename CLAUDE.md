# XploAds — notes for AI coding agents

Read `docs/IMPLEMENTATION_STATUS.md` first, then `docs/architecture/ARCHITECTURE.md`. Update
`IMPLEMENTATION_STATUS.md` at the end of every milestone (9-point format already used there).

## Commands

- Backend tests: `cd backend && pytest -q` (needs local PostgreSQL superuser via `TEST_PG_ADMIN_URL`, Redis on :6379/15)
- Backend lint: `cd backend && ruff check app tests alembic`
- Frontend: `cd frontend && npm run lint && npm run typecheck && npm run build`
- E2E: `cd frontend && E2E_BASE_URL=http://localhost:8080 npx playwright test` against a running stack
- Full stack: `docker compose up -d --build` → http://localhost:8080

## Rules that are easy to break

- Test documents: one `Test Cases/XploAds_PhaseN_Test_Cases.xlsx` and one `Test Results/XploAds_PhaseN_Test_Results.xlsx`
  per phase, at the repo root. Add both at the end of every phase.

- Never connect the API/workers as the table owner; RLS must apply. New tenant-owned tables need `tenant_id`,
  `ENABLE` + `FORCE ROW LEVEL SECURITY`, a `tenant_isolation` policy, grants to `xploads_app`, and a test in
  `tests/test_isolation.py`.
- Resolve tenant context only via `app.modules.tenant.api.deps` (`OrgContext` / `CurrentTenant`). Check permissions
  in services with `ctx.require("<code>")`; declare new codes in `tenant/permissions/catalog.py`.
- Migrations are hand-written SQL in `backend/alembic/versions/`, one linear history, prefixed by module.
- Cross-module side effects go through `app.shared.outbox.enqueue_event` in the same transaction; handlers must be idempotent.
- Money: `NUMERIC(20,6)` + currency, never float. Never publish ads or change budgets without an approval record.
- Third-party calls only in a module's `integrations/` adapter with a `mock` implementation; never claim a mock is live.
- Next.js 16 keeps visited routes mounted but hidden; in Playwright always filter locators with `{ visible: true }`.
- `frontend/AGENTS.md` is generated by Next.js: consult `node_modules/next/dist/docs/` for current APIs.
